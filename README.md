🎬 Growflix

Uma plataforma de streaming inspirada na Netflix, criada para centralizar conteúdos, podcasts e webinars sobre o universo da tecnologia e desenvolvimento!

💡 Sobre o Projeto

O Growflix nasceu com a ideia de unir o visual moderno e familiar das maiores plataformas de streaming do mercado a um catálogo focado em aprendizado e tecnologia.

A intenção foi construir uma interface limpa, fluida e intuitiva, onde a navegação é simples e o foco está no conteúdo de valor — desde conversas sobre carreira no Growcast até dicas práticas de código.

✨ O que você vai encontrar

Design Responsivo: Interface adaptada para navegação em desktop e dispositivos móveis.

Catálogo Temático: Organização de vídeos, lives e webinars focados em tecnologia.

Layout Familiar: Experiência de usuário baseada nas plataformas de streaming mais populares.

🛠️ Tecnologias Utilizadas

HTML5 & CSS3: Estruturação semântica e estilização completa do layout.

JavaScript: Manipulação de dados e interatividade da interface.

Vercel: Hospedagem e deploy contínuo da aplicação.

🚀 Como rodar o projeto localmente

Clone este repositório: git clone https://github.com/talitafranciskievicz/growflix.git

Abra a pasta do projeto no seu editor de código.

Abra o arquivo index.html ou home.html no seu navegador (ou utilize a extensão Live Server).
